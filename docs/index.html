How Forge embeds

Three layers, three jobs

Forge (private) is the brain: the memory (the backlog, the run log, the registry, the rules), the tools, and the agent's workspace. Nothing else can write it.
This panel (public) is the map: what runs, what calls what, what is missing, and the routes — derived from the repos themselves, so it cannot flatter the system.
The dashboard (public) is the vitals: what the system is — the products, their health, the conformance scores.

The chain is one-way and checkable: Forge writes the memory → the tools derive the facts → the panel and the dashboard publish them. A buyer can run the tools and get the same numbers, which is the point.

Why this is the commercial product

You are not selling an app. You are selling a system that governs itself — and can prove it.

Anyone can write a workflow. The thing that is hard to copy is a pipeline that audits its own drift, catches its own silent failures, backs up before every merge, and shows its work in public — with the numbers generated from the repositories rather than typed into a slide.

The licence sells Forge: the brain, the map and the vitals together. The apps stay free and open, which is what makes the map worth reading.
